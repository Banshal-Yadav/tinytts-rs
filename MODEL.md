# Model attribution

This repository contains a **runtime**, not a model. The weights are downloaded
separately and are not distributed here.

## Paradee-8M v1.1

| | |
|---|---|
| Source | https://huggingface.co/sahilmahendrakar/Paradee-8M-v1.1 |
| File used | `onnx/paradee_int8.onnx` (8.46 MB) |
| Author | Sahil Mahendrakar |
| License | **Apache-2.0** |
| Parameters | 7.88M |
| Voice | `af_heart` (single voice) |
| Language | English only, American pronunciation |
| Output | 24 kHz mono |
| Paper | [arXiv:2610.06817](https://huggingface.co/papers/2610.06817) |

The model card states: *"Apache 2.0, the same as Kokoro-82M."*

### Provenance

```
StyleTTS2 (yl4579/StyleTTS2-LJSpeech)
    -> Kokoro-82M (hexgrad/Kokoro-82M), Apache-2.0
        -> Paradee-8M v1.1 (sahilmahendrakar), Apache-2.0
```

Paradee-8M v1.1 is distilled from Kokoro-82M, which is itself derived from
StyleTTS2. The training code and the Python package are at
[github.com/sahilmahendrakar/paradee](https://github.com/sahilmahendrakar/paradee).

### Not affiliated

This runtime is an independent implementation. It is **unofficial** and is not
affiliated with, endorsed by, or supported by the model's author.

## Download

```bash
curl -L -o paradee_int8.onnx \
  https://huggingface.co/sahilmahendrakar/Paradee-8M-v1.1/resolve/main/onnx/paradee_int8.onnx
```

The fp32 variant (`onnx/paradee.onnx`, 35 MB) is also available and sounds the
same; this runtime has only been tested against the int8 file.

## Sample audio

The WAV files under `samples/` were generated by this runtime from the model
above, using the phoneme sequences in `vocab.txt`. They are outputs of an
Apache-2.0 model and are covered by the same license.

## What is not included

- Model weights (`*.onnx`) — gitignored, download from the link above
- Golden tensors (`golden*/`) — ~3.4 GB, regenerate with `scripts/verify/dump_golden.py`
- The Python baseline environment (`.venv/`) — see the model card for the
  upstream package
